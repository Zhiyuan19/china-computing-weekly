7-3 本周应用场景深度解读

专题一：智能体规模化落地引爆 Token 算力需求范式重构

📌 事件：IDC+浪潮《2026年中国人工智能计算力发展评估报告》重磅发布

背景：2026年10月12日，IDC联合浪潮信息正式发布首份智能体基础设施研究报告，系统预测全球及中国智能体演进路径与算力需求拐点。报告核心判断——"算力产业由'服务模型训练'转向'支撑持续智能作业'"，AI 基础设施竞争核心从"拥有多少算力"进一步转向"能够多高效地持续产出智能"。

核心数据

① 全球活跃智能体数量将从2026年的7940万个激增至2030年的22.16亿个，CAGR 高达129.8%；同期全球 Token 消耗量 CAGR 达4822.6%，约为活跃智能体数量增速的37倍。中国活跃智能体 CAGR 151.2%，中国 Token 消耗 CAGR 高达3499.3%。

② 2026 年中国智能算力规模将达2576.5 EFLOPS，同比增长87.9%；到2030年将达10524.3 EFLOPS。中国 AI 算力市场规模预计达515亿美元（同比+37%），2030年有望达1501亿美元。

③ 全球 AI 算力供需缺口将进一步扩大：需求满足率由2024年的79%下降至2027年的71%，2030年仅回升至77%，意味着约23%的需求长期等不到供应。

④ 城市格局重塑：深圳首次跻身中国 AI 算力城市前三，超过上海。"京杭深沪穗"前五格局确立——北京176.84亿美元、杭州48.08亿美元、深圳37.43亿美元、上海33.16亿美元、广州21.49亿美元智算基础架构投资。

三大要点深度解读

要点一（推理算力取代训练算力成主战场）：大模型时代算力消耗集中于阶段性、集中式预训练；智能体时代，推理算力取代训练算力成为全球算力消耗的主战场。这意味着传统面向训练的存量算力出现"算力错配"——大模型训练与智能体推理的高吞吐、长上下文存储需求严重不匹配。

要点二（能力型 vs 容量型算力分化）：浪潮信息首席AI战略官刘军提出智能体时代算力分化为两类形态——能力型算力（支撑前沿技术突破，服务超大模型训练与复杂场景推理）与容量型算力（支撑海量场景落地，保障制造、医疗、能源等行业智能体常态化运行）。前者追求算力峰值，后者追求性价比与可获得性。

要点三（行业落地成熟度严重分化）：代码开发和办公任务已率先进入规模化应用阶段（依托 OpenClaw 等开源框架），但制造、医疗健康、能源/电力等行业真正进入核心业务并形成"执行—反馈—优化"闭环的比例仍为0%；运营商虽已有70.0%接入部分业务流程，但进入核心业务闭环的比例仅3.3%。

预判

未来 12 个月，AI 算力投资将明显从"训练集群"转向"推理集群+边缘节点"。具备 HBM、高速光网络、智能体专用 CPU 等能力的国产算力供应商（如华为昇腾、阿里平头哥、壁仞、海光）将率先享受增量红利；液冷、超节点、CoWoS 先进封装赛道将进入产能爬坡期，2027年前产能锁定已成为头部厂商竞争焦点。

专题二：中国大模型Token消耗量逆袭，OpenRouter 周榜前二被国产模型占据

📌 事件：OpenRouter 数据显示中国模型周 Token 消耗占比突破65%，阶跃星辰 Step 5 Preview 登顶周榜全球第二

背景：2026年10月13日，中信里昂证券（CLSA）发布最新研报，基于主流大模型聚合平台 OpenRouter 的监测数据指出：截至9月底，全球每周 Token 消耗总量已突破146万亿，平台模型合计年经常性收入（ARR）突破15亿美元。其中中国大模型凭借相较美国同业约80%的价格折让，9月占据平台约65%的 Token 消耗量与30%的美元支出总额，呈现"杰文斯悖论"式增长。

核心数据

① 结构性逆转：2026年1月美/中顶尖大语言模型供应商分别占 OpenRouter Token 消耗65%/22%；9月已变为美国31%、中国65%。美元支出端，美国供应商从94%降至70%，中国从6%升至30%。

② 增速惊人：中国模型每周支出本年至今累计升27倍，由 token 用量升67倍带动，混合 token 价格则几乎减半。

③ 开源权重爆发：开源权重模型在 OpenRouter 上已占据29%的收入份额，表明中国 AI 实验室通过云算力合作伙伴进行生态分销具备强劲的商业化可行性。

④ 阶跃星辰 Step 5 Preview（10.15开源）：采用稀疏 MoE 架构，总参数600B、激活参数仅27B，支持100万 Token 上下文窗口，Artificial Analysis Intelligence Index 取得44分（全球开源前三）。开源后7天用量约18.8万亿 Token，登顶 OpenRouter 周榜全球第二、日榜全球第二。

三大要点深度解读

要点一（价格驱动的需求扩张）：中国模型在海外开发者生态中的渗透路径清晰体现了低成本带来的规模效应。Anthropic 在10月8日被迫将 Claude Haiku 5.5 输入价格下调90%（降至0.10美元/百万 tokens），几乎同一时间 OpenAI 上线 GPT-6 Luna 免费版——这是头部美国实验室首次正面承认"必须用低价回应中国模型"。

要点二（编程场景成为消耗主战场）：全球 AI Token 用量中超过一半与编程及其他计算机任务相关，国产模型在代码生成、长上下文、多语言翻译（腾讯 Hy-MT2、DeepSeek-V4-Pro、阶跃 Step 5 Preview）等维度形成系统性竞争力。Step 5 Preview 近七日18.8万亿 Token 中，相当部分来自 Cursor、Claude Code 等编程 Agent 工作流。

要点三（生态分销与算力协同）：中国实验室通过阿里云、腾讯云、火山引擎、华为云等算力伙伴进行 Token 计费分成，OpenRouter 上29%收入归属开源权重模型。这一渠道变现路径，叠加低毛利高周转，使国产模型不必依赖单一定价即可获得规模收入，但也意味着对云厂商算力调度能力的强依赖。

预判

未来 1—2 周内，OpenRouter 周榜前五中将稳定出现至少3个中国模型。编程 Agent、多模态 Agent、企业级 Agent 三个场景将成为下一轮 Token 消耗爆发点。需关注：① 头部厂商是否会进一步降价至零利润以争夺编程场景；② 中国算力云厂商在 OpenRouter 渠道变现中的份额变化；③ 海外开发者对中国模型的合规审查升级。
