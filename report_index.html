📋 执行摘要

①政策重磅：9月10日《中国词元工厂发展白皮书（2026）》发布，建立"有效词元(Good Token)"算力服务计价单元与四层产能漏斗评价体系，行业焦点从"能否获取算力"转向"能否稳定产出有价格竞争力的有效词元"；同日央视专题聚焦"十万卡集群"，工信部《信息通信行业"十五五"规划》明确2030年全国智能算力9800 EFLOPS、PUE≤1.2。9月9日北京"十五五"双规划将"词元工厂"写入省级文件，七部门联合印发《数字化绿色化协同转型实施方案》。政策从"建算力"迈入"算有效产能"新阶段。
②市场涨价：经济日报9月8日头版《算力涨价，还会涨多久？》定性"此轮涨价是AI产业从补贴扩张走向商业可持续的标志性节点"——腾讯云、阿里云、百度智能云密集调价部分超30%；DeepSeek API V4-Pro峰时输出价从6元升至27元/百万Token（+3.5倍）。Ornn数据9月第1周H100 SXM 3.06美元/小时（周环比+6.8%）、B200 6.42美元/小时（+5.9%）。同日报道全国500座智算中心空置率超50%、部分十万卡国产机房上架率不足20%，"一半海水一半火焰"分化加剧。
③区域扩张：9月9日21经济网实地走访和林格尔：投用算力规模超12.5万P（智算占比超95%）、绿电使用率≥80%、预制模块化方舱最快100天机电交付。9月8日发布跨区域算力合作"政策-技术-产业"三元驱动模型，面向京津冀、长三角等八大枢纽节点复制。工信部"十五五"规划2030年目标9800 EFLOPS——全国一体化算力网进入"高基数+绿电+利用率"三维考核新阶段。
④国产突破：路透9月10日报道华为、寒武纪、沐曦、天数智芯集体上调AI芯片报价20-50%——昇腾950DT指示价25万元+（较两月前+20-50%）、昇腾950PR由年初6万涨至8万+。同日昆仑芯P800万卡集群成功点亮，客户覆盖招商银行、南方电网、中国钢研等上百家行业龙头，星展展望估值4000-5000亿港元。彭博9月4日披露DeepSeek向华为下单16万颗950DT/25.6亿美元（2027年起分批投运内蒙古1GW数据中心），国产最大单笔订单落定。
⑤推理主导：寒武纪Day 0适配DeepSeek V4.1 Flash（KV缓存压缩至初代1/437倍、HBM需求降至1/4），完成GLM/DeepSeek/Qwen/Kimi/智谱五大国产大模型推理全适配。9月10日DeepSeek V4.1 Flash发布，综合性能超越V4 Pro、请求将按Flash单价计费。财通证券预测国产超节点机柜市场2026年759亿元→2027年2256亿元。中兴通讯"四V框架"深化连接+算力双引擎，2026H1算力收入+55%。技术进入"模型-芯片-框架"全链路闭环阶段。
⑥供应链博弈：9月10日寒武纪回应涨价传闻：上半年营收59.96亿（+108%）、归母净利23.11亿（+123%），预付款29.14亿（+291%）、存货82.48亿（+67%）——HBM备货史无前例。同日A股存储芯片活跃，SK海力士美股+7.05%、市值1.45万亿美元创新高，KB证券警告三星/SK海力士库存不足10天、HBM4晶圆需求是传统DRAM的3倍，预计2027年DRAM/NAND需求超供应10个百分点以上。京东云×摩尔线程签约十万卡国产智算集群，国产GPU首次进入头部互联网云核心。
⑦应用商业化：9月10日Cypher Asia香港峰会聚焦RWA代币化资管、链上固收与量化对冲；同日九方智投"股道智航"进入AI+量化证券投顾4.0时代，上半年研发投入1.7亿元（+13.7%）。9月9日美团LongCat-2.0万亿参数大模型亮相服贸会，万卡国产算力集群全流程训练，智能掌柜累计服务130万家商家、解决860万问题。中国AI模型周调用量9月1-7日达56.72万亿Token（周环比+2.83%），持续领跑全球；9月8日国内首款AI辅助创新药艾普司韦获批上市。AI应用从"对话"走向"垂直+合规"双轮驱动。
⑧广东韶关集群：本期信息表共收录广东省内智算与数据中心招标/中标/备案40项（按日期倒序9.4-9.10）。运营商+政府分点：中国电信18条（浈江A3A4 EPC恢复、土建+机电五标段跟踪审计、A7机电通信配套及20余项物资预采购、A6国产化万卡智算池重新招标）；中国移动6条（跨地市滚动：惠州一期外电、汕头二期外电扩容、佛山三水智算机房CDU改造、韶关浈江横三路与韶塘变电站接入咨询、机电EPC框架第二批、三年期项目管理）；中国联通4条（华南东莞机房运维与系统集成）；政府事业单位及政采12条（韶关起步区曲江片区公共管道、区域电算协同一体化、博晨算力中心外围等）。关键节点：电信浈江2.2期（A3A4）EPC恢复及延期；移动2026年广东数据中心机电EPC框架（第二批）；联通华南东莞IDC新增；武江龙归扩区一期配套+4094亩规划同步定标。韶关集群进入"多期滚动发包+算电协同"冲刺期。
